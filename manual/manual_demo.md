## 1. 서비스 개요

WaveHome이 제공하는 서비스와 주요 기능, 매뉴얼에서 사용하는 용어를 설명합니다.

<a id="sec1-1"></a>

### 1.1 WaveHome 서비스 소개

WaveHome은 **수면 관리, 전력 관리, 가전 제어를 하나의 화면에서 확인하고 관리하는 스마트홈 서비스**입니다. 집 안의 센서와 가전에서 수집한 정보를 보기 쉬운 형태로 제공하고, WaveAI가 사용자의 생활 패턴을 분석해 필요한 정보와 행동을 제안합니다.

사용자는 대시보드에서 현재 상태를 빠르게 확인한 뒤, WaveHome의 **세 가지 주요 기능인 수면 관리·전력 관리·가전 제어** 화면에서 세부 정보를 확인할 수 있습니다. 자연어로 질문하거나 가전을 제어하고 싶을 때는 WaveChat을 사용합니다. **디지털 트윈홈과 주간 계획**은 WaveHome을 더 편리하게 활용하도록 돕는 부가 기능입니다.

> **알아두기**
>
> WaveHome에서 제공하는 수면·생활 분석은 생활 습관 관리를 돕기 위한 참고 정보입니다. 의료 진단이나 공식 전기요금 고지서를 대신하지 않습니다.

## 2. 시작하기

WaveHome 사이트에 접속하고 첫 사용 안내와 기본 화면 구성을 확인합니다.

<a id="sec2-1"></a>

### 2.1 WaveHome에 접속하기

WaveHome은 별도의 프로그램을 설치하지 않고 웹 브라우저에서 사용할 수 있습니다.

1. **WaveHome 사이트 주소**를 주소창에 입력합니다.
2. 처음 방문한 경우 WaveHome 소개 화면을 확인합니다.
3. 소개 화면의 **시작하기** 버튼을 눌러 서비스 화면으로 이동합니다.

![WaveHome 첫 화면](./img/01_access_wavehome.png)

*WaveHome 첫 화면*

<a id="sec2-2"></a>

### 2.2 사용 안내 따라가기

대시보드에 처음 들어가면 메뉴와 주요 카드를 설명하는 사용 안내가 표시될 수 있습니다.

1. 화면에서 밝게 강조된 카드를 확인합니다.
2. 안내 문구를 읽고 **다음** 버튼을 누릅니다.
3. 마지막 안내까지 확인한 뒤 **완료**를 누릅니다.
4. 안내를 즉시 종료하려면 닫기 버튼을 누릅니다.
5. 다음 접속부터 안내를 표시하지 않으려면 **다시 보지 않기**를 선택합니다.

![대시보드 위에 표시된 사용 안내 말풍선](./img/02_onboarding.png)

*대시보드 위에 표시된 사용 안내 말풍선*

<a id="sec2-3"></a>

### 2.3 기본 화면 구성

| 영역 | 설명 |
| --- | --- |

## 3. 대시보드

대시보드는 WaveHome에 접속한 뒤 가장 먼저 확인하는 화면으로, 현재 생활 상태와 오늘 필요한 정보를 요약합니다.

<a id="sec3-1"></a>

### 3.1 어젯밤 수면

어젯밤 수면 카드에서는 목표 수면 시간과 실제 수면 시간의 비교, 입면 시각, 기상 시각과 오늘 밤 추천 수면 시간을 확인할 수 있습니다.

수면 점수, 수면 단계, 코골이·심박수·호흡수와 같은 상세 정보와 수면 인사이트를 확인하려면 카드를 눌러 **수면 관리** 페이지로 이동합니다.

![대시보드의 어젯밤 수면 카드](./img/03_dashboard_sleep.png)

*대시보드의 어젯밤 수면 카드*

<a id="sec3-2"></a>

### 3.2 예정된 알람

예정된 알람 카드에서는 오늘 또는 다음 날 실행될 알람의 이름, 실행 예정일과 시간을 확인할 수 있습니다.

새 알람을 추가하거나 기존 알람의 시간·요일·실행 방법을 변경하려면 카드를 눌러 **수면 관리 > 스마트 알람** 페이지로 이동합니다.

![대시보드의 예정된 알람 카드](./img/04_dashboard_alarm.png)

*대시보드의 예정된 알람 카드*

<a id="sec3-3"></a>

### 3.3 전력 관리

전력 관리 카드에서는 전체 콘센트의 현재 사용 전력, 전압, 전류, 시간당 예상 비용과 최근 전력 사용 추세를 확인할 수 있습니다.

기기별 사용량, 기간별 그래프와 전력 절약 인사이트를 확인하려면 카드를 눌러 **전력 관리** 페이지로 이동합니다.

![대시보드의 전력 관리 카드](./img/05_dashboard_power.png)

*대시보드의 전력 관리 카드*

<a id="sec3-4"></a>

### 3.4 홈 현황

홈 현황 카드에서는 온도·습도·조도 등의 실내 환경값, 수면 모니터링 레이더의 상태와 연결된 가전의 수 및 연결 상태를 확인할 수 있습니다.

장치의 활성화 여부나 연결 상태를 관리하려면 **설정 > 장치** 페이지로 이동합니다. 장치를 침실·거실 등 특정 공간에 배치하거나 구역 정보를 변경하려면 **설정 > 구역** 페이지로 이동합니다.

![대시보드의 홈 현황 카드](./img/06_dashboard_home.png)

*대시보드의 홈 현황 카드*

<a id="sec3-5"></a>

### 3.5 활성화된 제스처 목록

활성화된 제스처 카드에서는 현재 사용 중인 제스처의 이름과 각 제스처에 연결된 가전 동작을 확인할 수 있습니다. 여러 제스처가 등록된 경우 좌우 이동 버튼으로 다른 항목을 확인합니다.

제스처 세트와 인식 조건 등 자세한 정보를 보려면 **가전 제어 > 제스처 목록** 페이지로 이동합니다. 제스처를 새로운 가전 동작과 연결하려면 **가전 제어 > 자동화·예약** 페이지에서 자동화 규칙을 만듭니다.

![대시보드의 활성화된 제스처 카드](./img/07_dashboard_gesture.png)

*대시보드의 활성화된 제스처 카드*

### 3.6 오늘 할 일

오늘 할 일 카드에서는 주간 계획에 등록된 오늘의 일정, 남은 할 일의 수와 각 항목의 완료 여부를 확인할 수 있습니다. 완료한 항목은 카드에서 바로 체크할 수 있습니다.

일정의 시간대를 확인하거나 새로운 일정을 추가·수정·삭제하려면 카드를 눌러 **주간 계획** 페이지로 이동합니다.

> **알아두기**
>
> 대시보드와 주간 계획의 오늘 할 일은 같은 목록을 사용하므로 한쪽에서 변경한 완료 상태가 다른 화면에도 반영됩니다.

## 4. WaveChat

WaveChat은 생활 정보를 질문하고 가전·일정·알람을 자연어로 제어하는 AI 대화 화면입니다.

<a id="sec4-1"></a>

### 4.1 WaveChat 화면 열기

1. 왼쪽 메뉴에서 **WaveChat**을 선택해 전체 화면 채팅을 엽니다.

3. 작은 채팅창에서 전체 화면으로 이동하려면 확대 또는 크게 보기 버튼을 누릅니다.

2. 대화 오른쪽의 더보기 버튼을 누릅니다.

6. 대화를 삭제하려면 **제거**를 선택합니다.

## 6. 전력 관리

전력 관리에서는 전체 또는 개별 전력 소스의 실시간 상태, 기간별 사용량과 WaveAI 인사이트를 확인합니다.

<a id="sec6-1"></a>

### 6.1 전력 상태 확인하기

1. 왼쪽 메뉴에서 **전력 관리**를 선택합니다.
2. 상단 요약 카드에서 현재 전력, 전압, 누적 사용량과 예상 요금을 확인합니다.
3. 그래프 위의 `W`, `V`, `A`, `Wh` 중 확인할 항목을 선택합니다.
4. 실시간 변화를 보려면 1분, 10분, 30분 또는 1시간 범위를 선택합니다.
5. 누적 사용량을 보려면 `Wh`를 선택한 뒤 일간, 주간, 월간 또는 연간을 선택합니다.
6. 그래프 위에 마우스를 올려 해당 시점의 값을 확인합니다.

> **알아두기**
>
> - `W`(와트): 현재 순간적으로 사용하고 있는 전력의 크기입니다. 값이 클수록 해당 시점에 더 많은 전력을 사용하고 있다는 뜻입니다.
> - `V`(볼트): 전기를 흐르게 하는 전압의 크기입니다.
> - `A`(암페어): 현재 흐르고 있는 전류의 크기입니다.
> - `Wh`(와트시): 일정 시간 동안 사용한 전력량입니다. 예를 들어 100 W 기기를 1시간 사용하면 100 Wh를 사용한 것입니다.
>
> 전력량과 예상 비용은 선택한 전력 소스와 조회 구간을 기준으로 계산됩니다. 실제 요금은 기본요금과 계절별·구간별 요금에 따라 달라질 수 있습니다.

![전력 관리 전체 화면](./img/19_power_status.png)

*전력 관리 전체 화면*

<a id="sec6-2"></a>

### 6.2 기기별 전력 사용량 확인하기

1. 전력 관리 화면 아래의 **전력 소스** 목록으로 이동합니다.
2. 전체 사용량을 보려면 **전체**를 선택합니다.
3. 개별 기기의 사용량을 보려면 원하는 기기를 선택합니다.
4. 선택한 기기의 현재 전력, 전압, 전류와 시간당 예상 비용을 확인합니다.
5. 전력 집계에서 제외할 기기는 해당 전력 소스의 스위치를 끕니다.

> **알아두기**
>
> 전력 소스 스위치는 집계 포함 여부를 변경합니다. 장치의 실제 전원을 끄거나 연결 상태를 바꾸는 스위치가 아닙니다.

![전력 소스 목록](./img/20_power_sources.png)

*전력 소스 목록*

<a id="sec6-3"></a>

### 6.3 전력 인사이트

1. 확인할 전력 소스와 조회 기간을 선택합니다.
2. 화면 아래의 **전력 인사이트** 영역으로 이동합니다.
3. 절약 제안의 근거와 예상 효과를 확인합니다.
4. 적용할 제안은 실행 또는 적용 버튼을 누릅니다.

![전력 리포트와 인사이트 카드](./img/21_power_insight.png)

## 7. 가전 제어

가전 제어에서는 연결된 장치를 직접 조작하고 자동화·예약·적외선 명령·제스처와 제어 기록을 관리합니다.

<a id="sec7-1"></a>

### 7.1 가전 직접 제어하기

1. 왼쪽 메뉴에서 **가전 제어**를 선택합니다.
2. 상단에서 **제어** 탭을 선택합니다.
3. 기기 목록 위에서 전체 또는 침실·거실 등 구역 필터를 선택합니다.
4. 제어할 기기 카드를 선택합니다.
5. **기기 메뉴**에서 전원, 밝기, 색상, 채널 등 장치가 지원하는 기능을 변경합니다.

> **알아두기**
>
> 장치마다 사용할 수 있는 제어 항목이 다릅니다. 기기를 선택했을 때 표시되는 메뉴만 사용할 수 있습니다.

![가전 제어의 제어 탭](./img/22_iot_control.png)

*가전 제어의 제어 탭*

<a id="sec7-2"></a>

### 7.2 자동화 규칙 만들기

자동화는 제스처, 장치 상태, 센서값 또는 적외선 신호가 조건에 맞을 때 가전을 실행합니다.

1. 가전 제어에서 **자동화·예약** 탭을 선택합니다.
2. 자동화 영역의 **+ 새 자동화**를 누릅니다.
3. 자동화 종류를 선택합니다. 예: 제스처, 장치 상태, 적외선 감지.
4. 선택한 자동화 종류에 따라 조건 장치와 세부 조건을 설정합니다.
5. 동작시킬 가전과 실행할 동작을 선택합니다.
6. 한 번, On/Off 전환 또는 연속 실행 중 실행 방식을 선택합니다.
7. 필요하면 반복 간격과 쿨다운 시간을 설정합니다.
8. 자동화 이름과 요약을 입력한 뒤 **완료**를 누릅니다.

#### 자동화 관리

- 목록의 스위치로 자동화를 활성화하거나 비활성화합니다.
- 특정 자동화 규칙을 선택해 조건과 동작을 수정하거나 삭제합니다.
- **테스트**를 눌러 조건 없이 동작을 시험합니다.

![새 자동화 버튼과 자동화 목록](./img/23_automation.png)

*새 자동화 버튼과 자동화 목록*

### 7.3 가전 제어 예약하기

예약은 한 번 또는 반복되는 특정 시간에 가전을 실행합니다.

1. 가전 제어의 **자동화·예약** 탭에서 예약 영역을 찾습니다.
2. **+ 새 예약**을 누릅니다.
3. 한 번, 매일 또는 매주 중 반복 방식과 시간을 선택합니다.
4. 동작시킬 가전과 실행할 동작을 선택합니다.
5. 한 번, On/Off 전환 또는 연속 실행 중 실행 방식을 선택합니다.
6. 예약 이름과 요약을 입력한 뒤 **완료**를 누릅니다.

#### 예약 관리

- 목록의 스위치로 예약을 활성화하거나 비활성화합니다.
- 특정 예약을 선택해 시간과 동작을 수정하거나 삭제합니다.
- **테스트**를 눌러 조건 없이 동작을 시험합니다.

### 7.4 적외선 명령 사용하기

적외선 명령을 등록하면 IoT 기능이 없는 TV·에어컨과 같은 리모컨 가전을 WaveStation을 통해 제어할 수 있습니다.

1. 가전 제어에서 **적외선 명령** 탭을 선택합니다.
2. 새 명령을 등록하려면 **+ 새 명령**을 누릅니다.
3. 명령 이름과 설명을 입력합니다. (예: 에어컨 전원)
4. 적외선 신호를 받을 WaveStation을 선택하고 **리모컨 신호 받기**를 누릅니다.
5. 남은 시간이 표시되는 동안 WaveStation을 향해 등록할 리모컨 버튼을 한 번 누릅니다.
6. 신호 패턴이 자동으로 입력되었는지 확인합니다. 필요한 경우 측정값을 직접 입력할 수도 있습니다.
7. **저장**을 눌러 명령을 등록합니다.
8. 목록의 **테스트**를 눌러 실제 가전이 동작하는지 확인합니다.
9. 설정 버튼으로 수정하거나 휴지통 버튼으로 삭제합니다.

> **알아두기**
>
> 리모컨 신호를 받을 때는 WaveStation의 적외선 수신부를 향해 가까운 거리에서 버튼을 누릅니다.

![적외선 명령 등록 창과 명령 목록](./img/25_ir_command.png)

*적외선 명령 등록 창과 명령 목록*

2. 제스처 세트 목록에서 확인할 세트를 선택합니다.
3. 각 제스처의 행동과 구분을 확인할 수 있습니다.
4. 제스처로 가전을 동작시키려면 자동화·예약 탭에서 해당 제스처를 조건으로 새 자동화를 만듭니다.

> **알아두기**

## 8. 디지털 트윈홈(데모 버전)

디지털 트윈홈은 실제 집의 공간과 연결된 장치를 3D로 표현해 배치와 상태를 직관적으로 확인하는 화면입니다.

<a id="sec8-1"></a>

### 8.1 디지털 트윈홈 소개

기기 목록에서 장치를 직접 선택해 제어할 수 있고, WaveChat으로 실행한 제어 결과도 트윈홈 상태에 반영됩니다.

1. 왼쪽 메뉴에서 **디지털 트윈홈**을 선택합니다.
2. 처음 표시되는 사용 안내를 확인한 뒤 **둘러보기**를 눌러 3D 공간으로 이동합니다.
3. 마우스를 드래그해 시점을 회전하고, 마우스 휠로 화면을 확대하거나 축소합니다.
4. 특정 방을 선택해 내부를 확인하고, 집 전체로 돌아가려면 **전체 보기** 또는 돌아가기 버튼을 누릅니다.

![디지털 트윈홈 3D 전체 보기](./img/28_twin_intro_explore.png)

*디지털 트윈홈 3D 전체 보기*

<a id="sec8-2"></a>

### 8.2 공간과 장치 선택하기

1. **연결된 기기** 목록을 확인합니다.
2. 목록 위에서 전체 또는 특정 구역 필터를 선택합니다.
3. 확인할 장치를 목록에서 선택합니다.
4. 장치 상세 화면에서 현재 상태와 사용할 수 있는 제어 기능을 확인합니다.

1. 디지털 트윈홈의 안내창 또는 상단에서 WaveChat을 엽니다.
2. 제어할 방, 장치와 동작을 구체적으로 입력합니다. (예: 부엌 인덕션 꺼줘)
3. WaveAI의 기기 조회·제어 상태와 최종 답변을 확인합니다.

## 9. 주간 계획

주간 계획에서는 시간표 형태로 일정을 추가하고 오늘 할 일을 확인하며 AI 추천과 목표 코칭을 관리합니다.

<a id="sec9-1"></a>

### 9.1 일정 추가하기

1. 왼쪽 메뉴에서 **주간 계획**을 선택합니다.
2. 상단에서 확인할 주를 선택합니다. 이전·다음 날짜, 이전·다음 주 또는 달력을 사용할 수 있습니다.
3. 일정을 추가할 요일과 시간대의 빈 영역에 마우스를 올리고 표시되는 **+** 버튼을 누릅니다.
4. 일정 제목과 시작 시간, 종료 시간을 입력합니다.
5. 일정을 추가할 요일과 매주 반복 여부를 선택합니다.
6. 수면, 자세, 일정, 일상 등 일정 분류를 선택합니다.
7. 저장 버튼을 눌러 일정을 추가합니다.

![주간 계획 시간표에서 일정 추가](./img/31_weekly_add.png)

*주간 계획 시간표에서 일정 추가*

<a id="sec9-2"></a>

### 9.2 일정 수정 및 삭제하기

1. 시간표에서 수정할 일정 블록을 선택합니다.
2. 제목, 분류, 시작·종료 시간과 요일을 변경합니다.
3. 저장 버튼을 눌러 변경사항을 반영합니다.
4. 특정 일정을 빠르게 옮기려면 해당 블록을 원하는 요일과 시간대로 드래그합니다.
5. 일정을 삭제하려면 편집창의 삭제 버튼을 누릅니다.

![주간 계획 일정 편집창](./img/32_weekly_edit.png)

*주간 계획 일정 편집창*

<a id="sec9-3"></a>

### 9.3 오늘 할 일

1. **오늘 할 일** 영역에서 남은 할 일을 확인합니다.
2. 완료한 항목은 클릭하여 완료 표시를 합니다.
3. 다른 날짜의 할 일을 보려면 시간표 위의 날짜를 선택합니다.

> **알아두기**
>
> 오늘 할 일의 완료 상태는 대시보드의 오늘 할 일 카드와 함께 갱신됩니다.

![오늘 할 일](./img/33_weekly_todo.png)

*오늘 할 일*

<a id="sec9-4"></a>

### 9.4 목표 코칭

목표 코칭은 사용자가 입력한 하나의 활성 목표를 기준으로 WaveAI가 현재 추세와 실천 행동을 제안하는 기능입니다.

1. 주간 계획의 **목표 코칭** 영역으로 이동합니다.
2. 수면, 자세, 멘탈, 생활 또는 식습관 중 목표 분류를 선택합니다.
3. 이루고 싶은 목표를 구체적으로 입력합니다. (예: 평일에는 밤 11시 30분 전에 잠들기)
4. 목표 설정 버튼을 눌러 코칭을 요청합니다.
5. WaveAI가 제시한 과거 요약, 예상 흐름과 추천 행동을 확인합니다.
6. 일정에 반영할 추천은 적용 버튼을 누릅니다.

![목표 코칭 입력](./img/34_goal_coaching.png)
